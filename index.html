백업

불러오기는 현재 목록을 통째로 교체합니다. 기기 간 옮길 때는 ‘텍스트로 복사’ 후 메신저로 보내고, 받은 기기에서 ‘붙여넣어 불러오기’를 쓰세요.

전체 진행률

체크는 ‘가방에 담기 완료’를 뜻합니다. 구매 여부와는 별개예요.

보기 필터

참고용 준비물 목록입니다. 병원·조리원 준비물 안내에 맞춰 목록과 수량을 수정하세요.

🏥 산부인과 진료 메모

진료 때 들은 내용, 검사 결과, 다음 일정을 날짜별로 남겨 두세요. 체크리스트와 함께 이 기기에 저장되고 JSON 백업에도 포함됩니다.

    기록은 현재 기기의 브라우저에 저장됩니다. 다른 기기와 자동으로 동기화되지 않으며, 브라우저 데이터를 삭제하면 기록이 사라질 수 있습니다. 상단 백업 메뉴에서 JSON 파일로 내보내 보관하세요.
